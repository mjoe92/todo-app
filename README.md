# Todo App
A simple, responsive todo app built with plain HTML, Bootstrap 5 and vanilla JavaScript.

## Features
- ✅ **Create / Edit / Delete** tasks
- 👆 **Tap** a task to edit it; tap the circle to mark it done
- 👉 **Swipe right** to ignore a task (or use the button)
- 👈 **Swipe left** to delete a task (or use the button)
- 💾 Tasks are **saved in localStorage** — they persist across sessions
- 🔄 **Daily checkbox reset** — all checkboxes are cleared automatically each day
- 🌙 **Dark / light mode** with system-preference detection and manual toggle
- 📱 **Fully responsive** — works on phones and large screens

## Usage
Just open `todo-app.html` in any modern browser. No build step or server required.

## Keyboard shortcuts
| Key     | Action                |
|---------|-----------------------|
| `N`     | Open “New task” modal |
| `Enter` | Submit the modal form |
| `Esc`   | Close the modal       |

## Tech stack
- [Bootstrap 5.3](https://getbootstrap.com/)
- [DM Sans](https://fonts.google.com/specimen/DM+Sans) via Google Fonts
- Vanilla JavaScript (no frameworks)
